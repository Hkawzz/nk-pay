# Registro de problemas para a v0.9

Anote aqui **cada** problema encontrado no [teste profundo](roteiro-teste-profundo.md) da v0.8. **Não coloque valores reais nem prints com seus dados:** descreva com valores de exemplo.

## Gravidade
- **Alta:** número errado (saldo, devido, guardado, juros), dado perdido, app fecha sozinho, backup automático que não grava.
- **Média:** funciona, mas confunde ou exige um caminho torto; texto errado; falta um aviso importante.
- **Baixa:** visual, ortografia, sugestão de melhoria.
