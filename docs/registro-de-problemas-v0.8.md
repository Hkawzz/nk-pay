# Registro de problemas para a v0.8

Anote aqui **cada** problema encontrado no [teste profundo](roteiro-teste-profundo.md). É a entrada da v0.8 (a etapa final). **Não coloque valores reais nem prints com seus dados:** descreva com valores de exemplo.

## Gravidade
- **Alta:** número errado (saldo, devido, disponível, juros, guardado), dado perdido, app fecha sozinho.
- **Média:** funciona, mas confunde ou exige um caminho torto; texto errado; falta um aviso importante.
- **Baixa:** visual, ortografia, sugestão de melhoria.
